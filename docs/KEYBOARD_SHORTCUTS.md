# Graphite - Keyboard Shortcuts & Power User Guide

## Canvas Navigation
| Shortcut | Action |
|----------|--------|
| `Space + Drag` | Pan canvas |
| `Scroll` | Zoom in/out |
| `Ctrl + 0` | Reset zoom to 100% |
| `Ctrl + F` | Fit all nodes in view |
| `Ctrl + G` | Toggle grid snap |

## Node Operations
| Shortcut | Action |
|----------|--------|
| `N` | Create new chat node |
| `Ctrl + D` | Duplicate selected node |
| `Delete` | Remove selected node |
| `Ctrl + C / V` | Copy / Paste node |
| `Tab` | Quick-connect to new node |
| `Ctrl + Enter` | Send message in active node |

## Model Switching
| Shortcut | Action |
|----------|--------|
| `Ctrl + 1` | Switch to Ollama (local) |
| `Ctrl + 2` | Switch to OpenAI |
| `Ctrl + 3` | Switch to Gemini |
| `Ctrl + 4` | Switch to Anthropic |
| `Ctrl + 5` | Switch to Groq |

## Agent Mode
| Shortcut | Action |
|----------|--------|
| `Ctrl + A` | Toggle agent mode |
| `Ctrl + Z` | Undo last agent action |
| `Ctrl + B` | Set budget limit |
| `Esc` | Stop agent execution |

## Workspace
| Shortcut | Action |
|----------|--------|
| `Ctrl + S` | Save workspace |
| `Ctrl + O` | Open workspace |
| `Ctrl + N` | New workspace |
| `Ctrl + E` | Export conversation |
| `Ctrl + ,` | Open settings |

## Tips
- **Branch conversations**: Right-click any message → "Branch from here"
- **Pin important nodes**: Double-click node header
- **Color coding**: Right-click node → Set color for organization
- **Search across nodes**: `Ctrl + Shift + F` for global search
